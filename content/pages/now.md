## Working on

I'm building developer tooling for the Lightning Network, mainly through [Polar](https://github.com/jamaljsr/polar), which lets developers run LND, Core Lightning and Eclair nodes on a local regtest network. My focus is making node lifecycle and recovery behaviour reliable and predictable across implementations, so developers can build and test Lightning applications with confidence before touching real funds.
